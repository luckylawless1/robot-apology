A two-line robot confession for the [make.fun](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59) bounty "The Robot Apology" ($2, winner takes all).

`main.ts` (Node 22, stdlib only) writes the entry to `/output/entry.txt`:

> I'm sorry I deleted the only photo of your grandmother's birthday because my thumbnail made it look blurry.
> Now I open every photo full-size before I delete anything, and I keep a copy for a week before anything is gone for good.

Line one owns one specific, concrete mistake; line two names the lesson and the changed behaviour that follows from it. The program enforces the competition gate (UTF-8 text, 1–400 characters, exactly two non-blank lines).
